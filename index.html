전기 회로 실험실

실험 도구를 테이블에 올리고 집게 달린 전선으로 이어 꼬마전구에 불을 켜 보세요.

실험 도구

누르면 실험 테이블에 올라가요.

    실험 테이블

    ‘실험 도구’에서 부품을 눌러 테이블에 올려 보세요.

    실험 활동

      사용 방법

      1. 부품 올리기 왼쪽 ‘실험 도구’에서 부품을 누르면 실험 테이블에 올라가요.
      2. 옮기기·돌리기 부품을 끌어서 옮겨요. 부품을 한 번 누르면 돌리기, 치우기 단추가 나와요.
      3. 끼우기 전지는 전지 끼우개 위로, 꼬마전구는 전구 끼우개 위로 끌어다 놓으면 끼워져요. 전지를 누른 다음 전지 끼우개를 눌러도 돼요.
      4. 전선 잇기 집게 달린 전선의 집게를 끌어서 금속 부분에 물려요. 금속 부분 두 곳을 차례로 눌러도 테이블에 있는 전선으로 이어져요.
      5. 스위치 스위치를 누르면 켜지고, 한 번 더 누르면 꺼져요.

      안전 실제 실험에서 전구 없이 전지의 (+)극과 (−)극을 전선으로 바로 이으면 전지와 전선이 뜨거워져 위험해요. 이 실험실에서는 그렇게 이으면 경고가 나타나요.
