# 전기 회로 실험실

과학실 실험 도구가 고장 나 있어도 수업할 수 있도록 만든 가상 실험실입니다.
과학 6-2 「3. 전기의 이용」 교과서의 탐구 활동(60~66쪽)을 따라 만들었습니다.
학생이 실험 도구를 눌러 실험 테이블에 올리고, 집게 달린 전선으로 이어 전구에 불을 켜거나 전동기를 돌리고 전자석을 만듭니다.

## 실행 방법

설치할 것이 없습니다. 다음 중 편한 방법을 쓰세요.

- **파일로 열기**: 저장소를 내려받아 `index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 인터넷이 없어도 동작합니다(글꼴만 기본 글꼴로 바뀝니다).
- **웹 주소로 열기**: GitHub 저장소의 Settings → Pages에서 이 브랜치를 배포하면 학생들이 주소로 접속할 수 있습니다.

주소 끝에 `#lesson1`, `#lesson2`, `#lesson3`, `#free`를 붙이면 그 차시 화면으로 바로 열립니다.
크롬북, 태블릿(터치), 데스크톱 브라우저에서 쓸 수 있도록 마우스와 터치를 모두 지원합니다.

같은 회로 계산을 쓰는 게임 **시한폭탄 처리반**은 `game/index.html`에 있습니다. 아래 [게임: 시한폭탄 처리반](#게임-시한폭탄-처리반)을 보세요.

## 차시와 실험 활동

위쪽 탭에서 차시를 고릅니다. 차시마다 실험 도구와 실험 테이블이 따로 있고, 활동을 해내면 관찰한 것이 하나씩 표시되다가 모두 관찰하면 ‘성공’이 됩니다.

| 탭 | 교과서 | 실험 도구 | 실험 활동 |
| --- | --- | --- | --- |
| 1. 전구에 불 켜기 | 60~61쪽 | 전지, 전지 끼우개, 전구, 전구 끼우개, 스위치, 집게 달린 전선, 플라스틱·고무·금속 막대 | 실험 1 전구에 불 켜기 / 실험 2 전기가 흐르는 물질 확인하기 |
| 2. 전지의 직렬연결 | 62~63쪽 | 위 기본 도구, 전동기, 버저 | 실험 1 전구의 밝기 비교 / 실험 2 전동기 비교 / 실험 2 버저 비교 |
| 3. 전자석 | 64~66쪽 | 전지, 전지 끼우개, 스위치, 집게 달린 전선, 전자석, 둥근 철 고리, 나침반 | 실험 1 전자석 만들기 / 실험 2 전지의 개수와 전자석의 세기 / 실험 2 전지의 방향과 전자석의 극 |
| 자유 탐구 | | 모든 도구 | 없음 |

관찰 결과(불이 켜졌는지, 몇 개가 붙었는지 등)는 화면에 적어 주지 않습니다. 학생이 직접 보고 『실험관찰』에 기록하도록 ‘관찰함’ 표시만 합니다.
활동 문구와 순서는 `js/lessons.js`만 고치면 바뀝니다.

## 실험 도구 다루기

| 도구 | 하는 일 |
| --- | --- |
| 전지 | 1.5 V. (+)극과 (−)극에 바로 집게를 물릴 수도 있습니다. |
| 전지 끼우개 | 전지를 끌어다 놓으면 끼워집니다. 거꾸로 끼울 수도 있고 ‘전지 방향 바꾸기’로 돌릴 수 있습니다. 다른 전지 끼우개의 끝에 끌어다 대면 서로 붙어 직렬로 이어지고, ‘끼우개 떼기’로 뗍니다. |
| 전구 | 꼭지와 꼭지쇠에 각각 전선을 이어야 불이 켜집니다. 전구 끼우개에 끌어다 놓으면 끼워집니다. |
| 스위치 | 누르면 닫히고, 한 번 더 누르면 열립니다. |
| 집게 달린 전선 | 집게(색 있는 손잡이)를 끌어서 금속 부분에 물립니다. 금속 부분 두 곳을 차례로 눌러도 테이블에 있는 빈 전선으로 이어집니다. |
| 플라스틱·고무·금속 막대 | 양쪽 끝에 집게를 물립니다. 금속 막대만 전기가 흐릅니다. |
| 전동기 | 전기가 흐르면 날개가 돕니다. 전지를 두 개 직렬연결하면 더 빨리 돌고, 전지 방향을 바꾸면 반대로 돕니다. |
| 버저 | 빨간색 전선을 (+)극 쪽, 검은색 전선을 (−)극 쪽에 이으면 소리가 납니다. 위쪽 ‘소리’로 끌 수 있습니다. |
| 전자석 | 양쪽 에나멜선 끝에 집게를 물립니다. 전기가 흐를 때 끝부분을 둥근 철 고리에 가까이 하면 고리가 붙습니다. |
| 둥근 철 고리, 나침반 | 전자석 끝 가까이에 놓고 관찰합니다. 나침반 바늘은 전자석이 없으면 화면 위쪽(북쪽)을 가리킵니다. |

부품을 한 번 누르면 돌리기, 치우기 같은 단추가 나옵니다. 실제 실험 상자처럼 도구마다 꺼낼 수 있는 개수가 정해져 있습니다.
전구 없이 전지의 두 극을 전선으로 바로 이으면 ‘합선’ 경고가 나오고 전지와 전선이 빨갛게 달아오릅니다.
위쪽 ‘전기가 흐르는 길 보기’를 켜면 전선 위로 전기가 흐르는 방향((+)극 → (−)극)이 움직이는 점으로 보입니다.

## 게임: 시한폭탄 처리반

`game/index.html`을 엽니다. 폭탄의 ‘정지 회로’가 고장 나 있고, 고장 난 곳을 찾아 고쳐서 **정지 램프(전구)에 불이 켜지면** 폭탄이 멈춥니다.
시간 안에 못 고치면 폭탄이 터지고 한 판이 끝나며, 그때까지 해체한 폭탄 수가 기록이 됩니다.

### 고치는 방법

- 집게(색 있는 손잡이)를 끌어 금속 부분에 물립니다.
- 스위치는 누르면 닫힙니다. 전지 끼우개를 누르면 ‘전지 방향 바꾸기’, 전선을 누르면 ‘전선 빼기’가 나옵니다.
- 부품 상자의 새 전지, 새 전구, 금속 막대, 새 전선을 고장 난 부품 위로 끌어다 놓으면 바꿔 끼워집니다. 폭탄마다 하나씩만 있습니다.
- 힌트를 누르면 남은 고장 한 곳이 반짝이고 시간이 5초 줄어듭니다. 합선을 만들면 5초가 줄어듭니다(폭탄마다 한 번).

### 고장 종류

폭탄마다 부품 위치, 방향, 전선 색과 이어진 순서, 헷갈리게 하는 부품이 무작위로 바뀌어서 같은 고장도 매번 다르게 보입니다.
같은 고장은 잇달아 나오지 않고, 처음 보는 고장부터 나온 뒤에는 가장 오래 안 나온 고장 가운데에서 고릅니다.

| 단계 | 고장 | 교과서 |
| --- | --- | --- |
| 1~3번째 폭탄 | 빠진 집게, 열린 스위치, 빠진 전지, 빠진 전구 | 60~61쪽 전기 회로 |
| 4번째부터 | 부도체(플라스틱·나무)에 물린 집게, 전지 끼우개의 한쪽 단자에만 이은 전선, 끊어진 필라멘트, 끊어진 전선, 플라스틱·고무 막대 | 60~61쪽 도체와 부도체 |
| 8번째부터 | 전구 끼우개의 한쪽 단자에만 이은 전선(합선), 거꾸로 넣은 전지(직렬연결), 전지의 두 극을 바로 잇는 전선(합선) | 62~63쪽 전지의 직렬연결 |

9번째 폭탄부터는 고장이 두 곳인 폭탄이, 20번째부터는 세 곳인 폭탄이 섞여 나옵니다.
폭탄을 해체하면 고장 원인이 설명되고, 터지면 고장 난 곳이 빨간 동그라미로 표시됩니다.

### 제한 시간

처음 폭탄은 40초이고 폭탄마다 3초씩 줄어 12번째부터 7초입니다. 고장이 한 곳 늘 때마다 7초를 더 줍니다.
10초 이하로 남으면 타이머가 깜박이고 경고음이 빨라지므로, 11번째 폭탄부터는 처음부터 깜박입니다.
값은 `game/bomb.js`의 `timeLimit`에서 바꿀 수 있습니다.

### 기록

기록은 **그 기기(태블릿)의 브라우저에만** 저장되고, 기기마다 상위 10개(별명, 해체한 폭탄 수, 날짜)가 남습니다.
여러 학생이 한 기기를 쓰면 같은 기록판에 함께 쌓이고, 브라우저의 사이트 데이터를 지우거나 시크릿 창에서 열면 남지 않습니다.
반 전체 기록을 한곳에 모으는 기능은 없습니다. 학생 기록은 실명 대신 별명이나 번호로 남기기를 권합니다.

## 회로 계산 방식

`js/circuit.js`가 절점 해석법으로 각 부품에 걸린 전압과 흐르는 전류를 계산합니다. 수업용으로 단순하게 잡은 값입니다.

| 부품 | 모델 |
| --- | --- |
| 전지 | 1.5 V, 내부 저항 0.1 Ω |
| 전구 | 6 Ω 고정 저항. 밝기는 ‘전지 1개 + 전구 1개’ 회로를 1로 놓고 소비 전력으로 비교 |
| 전동기 | 5 Ω. 걸린 전압에 비례해 빨리 돎 |
| 버저 | 100 Ω. 빨간색 전선 쪽 전위가 높을 때만 전기가 흐름 |
| 전자석 | 2 Ω. 붙는 둥근 철 고리 수는 전류에 비례(전지 1개 약 3개, 2개 약 6개) |
| 전선, 닫힌 스위치, 금속 막대 | 0.01 Ω |
| 플라스틱·고무 막대, 열린 스위치 | 전기가 흐르지 않음 |

교과서 실험은 1차시에 1.5 V 전구, 2차시에 3.0 V 전구·전동기·버저를 쓰지만, 이 실험실은 전구를 한 종류만 둡니다.
값이 실제 부품 규격과 다르므로 밝기, 회전 속도, 소리 크기, 붙는 고리 수는 실제 실험과 똑같지 않습니다. ‘더 밝다, 더 빠르다, 더 많이 붙는다’를 비교하는 데 쓰세요.
