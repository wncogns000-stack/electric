# 전기 회로 실험실

과학실 실험 도구가 고장 나 있어도 수업할 수 있도록 만든 초등 과학 전기 회로 가상 실험실입니다.
학생이 실험 도구를 눌러 실험 테이블에 올리고, 집게 달린 전선으로 이어 꼬마전구에 불을 켭니다.

## 실행 방법

설치할 것이 없습니다. 다음 중 편한 방법을 쓰세요.

- **파일로 열기**: 저장소를 내려받아 `index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 인터넷이 없어도 동작합니다(글꼴만 기본 글꼴로 바뀝니다).
- **웹 주소로 열기**: GitHub 저장소의 Settings → Pages에서 이 브랜치를 배포하면 학생들이 주소로 접속할 수 있습니다.

크롬북, 태블릿(터치), 데스크톱 브라우저에서 쓸 수 있도록 마우스와 터치를 모두 지원합니다.

## 실험 도구

| 도구 | 하는 일 |
| --- | --- |
| 전지 | 1.5 V. (+)극과 (−)극에 바로 집게를 물릴 수도 있습니다. |
| 전지 끼우개 | 전지를 끌어다 놓으면 끼워집니다. 거꾸로 끼울 수도 있고, ‘전지 방향 바꾸기’로 돌릴 수 있습니다. |
| 꼬마전구 | 꼭지와 꼭지쇠에 각각 전선을 이어야 불이 켜집니다. |
| 전구 끼우개 | 꼬마전구를 끌어다 놓으면 끼워집니다. ‘전구 빼기’로 다시 뺄 수 있습니다. |
| 스위치 | 누르면 켜지고, 한 번 더 누르면 꺼집니다. |
| 집게 달린 전선 | 집게(색 있는 손잡이)를 끌어서 금속 부분에 물립니다. 금속 부분 두 곳을 차례로 눌러도 테이블에 있는 빈 전선으로 이어집니다. |

부품을 한 번 누르면 돌리기, 치우기 같은 단추가 나옵니다. 실제 실험 상자처럼 도구마다 꺼낼 수 있는 개수가 정해져 있습니다(전선 10개, 스위치 3개, 나머지 4개).

## 실험 활동

오른쪽 ‘실험 활동’에 다섯 가지 활동이 있고, 회로를 바르게 만들면 자동으로 ‘성공’ 표시가 됩니다.

1. 꼬마전구에 불 켜기
2. 스위치로 켜고 끄기 (전지 끼우개, 전구 끼우개, 스위치 사용)
3. 전구 2개 직렬연결
4. 전구 2개 병렬연결
5. 더 해 보기: 전지 2개 잇기

이 활동 구성은 초등 과학의 일반적인 ‘전기의 이용’ 단원 흐름을 바탕으로 만들었습니다. 수업에 쓰는 교과서와 순서나 용어가 다르면 `js/app.js`의 `MISSIONS` 목록을 고치면 됩니다.

그 밖에 이런 것도 관찰할 수 있습니다.

- 직렬연결은 병렬연결보다 전구가 어둡습니다.
- 직렬연결에서 전구 하나를 빼면 나머지도 꺼지고, 병렬연결에서는 켜진 채로 있습니다.
- 전지 2개를 같은 방향으로 이으면 더 밝아지고, 하나를 거꾸로 이으면 꺼집니다.
- 전구 없이 전지의 두 극을 바로 이으면 ‘합선’ 경고가 나오고 전지와 전선이 빨갛게 달아오릅니다.
- 위쪽 ‘전기가 흐르는 길 보기’를 켜면 전선 위로 전기가 흐르는 방향((+)극 → (−)극)이 움직이는 점으로 보입니다.

## 회로 계산 방식

`js/circuit.js`가 절점 해석법으로 각 부품에 흐르는 전류를 계산합니다. 수업용으로 단순하게 잡은 값입니다.

- 전지: 1.5 V, 내부 저항 0.1 Ω
- 꼬마전구: 6 Ω 고정 저항 (실제 전구는 온도에 따라 저항이 바뀌지만 여기서는 고정)
- 집게 달린 전선, 닫힌 스위치: 0.01 Ω
- 전구 밝기: 그 전구가 쓰는 전력을 ‘전지 1개 + 전구 1개’ 회로의 전력으로 나눈 값으로 정합니다.
- 합선: 전지에 2 A가 넘게 흐르면 합선으로 봅니다.

실제 꼬마전구의 규격과 다르므로 밝기 비율은 실제 실험과 똑같지 않습니다. 밝고 어두운 차이를 비교하는 데 쓰세요.

## 파일 구성

```
index.html        화면 구성
css/style.css     디자인 (밝은 화면·어두운 화면 모두 지원)
js/circuit.js     회로 계산
js/parts.js       실험 도구 그림과 치수
js/app.js         끌기, 연결, 실험 활동 판정
tests/            회로 계산 테스트
```
