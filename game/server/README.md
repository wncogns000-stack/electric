# 학급 기록판 설치하기 (구글 시트)

시한폭탄 처리반의 기록을 반 전체가 함께 쓰는 순위표로 모으고, 교사가 도전 시간을 열고 닫으려면 선생님의 구글 시트에 학급 기록판을 한 번 설치합니다.
학생은 로그인하지 않고 게임 주소만 열면 됩니다. 기록은 선생님 구글 드라이브의 시트에 쌓입니다.

설치하지 않아도 게임은 지금처럼 쓸 수 있고, 그때는 기록이 기기마다 따로 남습니다.

## 준비물

- 구글 계정 하나 (10분쯤 걸립니다)
- 개인 Gmail 계정을 권합니다. 학교에서 받은 Google Workspace 계정은 관리자 설정에 따라 ‘모든 사용자’에게 공개하는 웹 앱을 만들 수 없을 수 있습니다.

## 설치 순서

1. 구글 드라이브에서 **새 구글 스프레드시트**를 만듭니다. 이름은 자유입니다(예: 시한폭탄 처리반 기록판).
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장합니다.
4. 편집기 위쪽의 함수 목록에서 **setup**을 고르고 **실행**을 누릅니다.
   처음 한 번은 권한을 묻습니다. 계정을 고르고, ‘확인되지 않은 앱’ 화면이 나오면 **고급**을 눌러 이 프로젝트로 이동한 뒤 허용합니다.
   실행이 끝나면 시트에 **기록**, **도전 시간**, **설정** 탭이 생깁니다.
5. 시트의 **설정** 탭에서 ‘교사 암호’ 칸(B열)에 암호를 적습니다. 게임의 교사용 화면에서 이 암호를 씁니다. 학생에게 알려 주지 마세요.
6. Apps Script 편집기 오른쪽 위에서 **배포 → 새 배포**를 누릅니다. ‘유형 선택’ 옆의 톱니바퀴에서 **웹 앱**을 고르고 아래처럼 정한 뒤 **배포**합니다.
   - 실행할 사용자: **나**(선생님 계정)
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

화면의 메뉴 이름은 구글이 바꾸면 조금 다를 수 있습니다(영문 화면에서는 Deploy → New deployment → Web app, Execute as: Me, Who has access: Anyone).

## 게임에 연결하기

둘 중 하나를 고릅니다.

- **주소에 붙이기**: 게임 주소 뒤에 `?board=웹앱URL`을 붙여 학생들에게 나눠 줍니다.
  예: `https://…/game/?board=https://script.google.com/macros/s/AKfy…/exec`
- **설정 파일에 넣기**: `game/config.js`의 `board: ''` 따옴표 안에 웹 앱 URL을 넣습니다. 그러면 게임 주소만 나눠 주면 됩니다.

연결되면 게임 첫 화면에 도전 시간과 ‘우리 반 순위’, ‘교사용 · 도전 시간 관리’ 단추가 나옵니다.

게임은 GitHub Pages처럼 일반 웹 주소에 올린 것이나 내려받은 `game/index.html` 파일로 열어야 합니다.
claude.ai 아티팩트 링크로 열면 외부 연결이 막혀 기록판에 닿지 못할 수 있습니다(확인하지 못했습니다).

## 수업에서 쓰기

게임 첫 화면 아래의 **교사용 · 도전 시간 관리**를 누르고 암호를 넣습니다.

- **지금 열기**: 10~40분 동안, 또는 닫을 때까지 바로 엽니다.
- **지금 닫기**: 바로 닫습니다. 그때 하고 있던 판은 닫힌 뒤 10분 안에 끝나면 기록됩니다.
- **도전 시간 예약**: 날짜와 시작·끝 시각을 정해 둡니다. 여러 개를 예약할 수 있어서 반마다 수업 시간에 맞춰 열 수 있습니다.
- **기록판 새로 시작**: 지금까지의 기록을 ‘보관 날짜’ 탭으로 옮기고 순위표를 비웁니다. 두 번 눌러야 합니다.

시트에서 직접 고쳐도 됩니다. **도전 시간** 탭에 시작·끝 시각을 적으면(끝을 비우면 닫을 때까지) 10초쯤 뒤 게임에 반영됩니다.
학생 화면은 30초마다, 그리고 도전 시간이 열리고 닫히는 시각에 맞춰 새로 확인합니다.

## 순위를 매기는 방법

- 학생마다 **가장 많이 해체한 판 하나**로 순위를 매깁니다. 같은 개수면 같은 순위이고, 먼저 세운 학생이 위에 옵니다.
- 이름이 같으면(띄어쓰기 무시) 같은 학생으로 칩니다. 같은 이름의 학생이 있으면 ‘12번 김하늘’처럼 번호를 붙이게 하세요.
- 모든 판(0개 포함)이 **기록** 탭에 한 줄씩 남으므로 학생별 도전 횟수도 볼 수 있습니다. ‘기기’ 열은 같은 이름이 여러 기기에서 왔는지 볼 때 씁니다.
- 연결이 끊긴 채 끝난 판은 그 기기에 두었다가 다시 연결될 때 보냅니다. 같은 판은 한 번만 기록됩니다.

## 알아 둘 점

- 학생 이름은 선생님 시트에 저장되고, 순위표는 게임을 연 모든 학생에게 보입니다. 실명 대신 번호나 별명을 쓸지 학급 사정에 맞게 정하세요.
- 웹 앱 주소를 아는 사람은 누구나 기록을 보낼 수 있습니다. 도전 시간과 기록판 비우기는 교사 암호로 막지만, 기록을 꾸며 보내는 것까지 완전히 막지는 못합니다.
- `Code.gs`를 고쳤다면 **배포 → 배포 관리**에서 새 버전으로 다시 배포해야 반영됩니다. 웹 앱 주소는 그대로입니다.
- 구글 Apps Script에는 사용량 제한이 있습니다(공식 문서 기준 한 계정에서 동시에 30개 실행). 한꺼번에 몰리면 잠깐 연결에 실패할 수 있고, 게임은 다음 확인 때 다시 시도합니다.
